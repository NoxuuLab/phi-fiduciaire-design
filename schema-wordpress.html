Schema JSON-LD — Instructions d'implémentation

Ce document contient tous les blocs JSON-LD (Schema.org) à intégrer sur chaque page du site WordPress de PHI Fiduciaire.

Option A — Rank Math
Ouvrir la page → Rank Math → Schema → Add Schema → Custom Schema → coller le JSON → Save.
Option B — functions.php
Injecter via wp_head dans le thème enfant, conditionné par l'URL canonique de chaque page.
Important
Toutes les URLs utilisent la structure /fr/ pour la gestion multilingue (fr / en / pl).
